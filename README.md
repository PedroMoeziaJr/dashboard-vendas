📊 Dashboard de Vendas em Excel
Este repositório contém um dashboard de vendas desenvolvido em Microsoft Excel como parte de um trabalho acadêmico. O objetivo do projeto é transformar dados brutos em visualizações claras, permitindo uma análise rápida e eficiente dos principais indicadores de desempenho comercial.

🎯 Objetivo do Projeto
Criar uma ferramenta visual que facilite a interpretação dos dados de vendas, permitindo:
- Identificação de tendências ao longo do tempo
- Comparação entre produtos, regiões ou vendedores
- Acompanhamento de metas e resultados
- Tomada de decisão baseada em dados

📁 Conteúdo do Repositório
- /dados – Arquivos utilizados como base para o dashboard
- /dashboard – Arquivo Excel contendo o painel final
- README.md – Documentação do projeto
(Você pode ajustar essa parte conforme a estrutura real do seu repositório.)

🛠️ Ferramentas Utilizadas
- Microsoft Excel
- Tabelas dinâmicas
- Gráficos dinâmicos
- Segmentações de dados
- Fórmulas e funções
- Formatação condicional

📈 Funcionalidades do Dashboard
- Visão geral das vendas totais
- Análise por período (mensal, trimestral, anual)
- Ranking de produtos ou vendedores
- Indicadores de desempenho (KPIs)
- Filtros interativos para navegação dos dados

🚀 Como Utilizar
- Baixe o arquivo Excel disponível no repositório
- Abra o arquivo no Microsoft Excel (versão 2016 ou superior recomendada)
- Utilize os filtros e segmentações para explorar os dados
- Analise os gráficos e indicadores conforme sua necessidade

📌 Observações
- Os dados utilizados podem ser fictícios ou anonimizados, dependendo das exigências do curso.
- O dashboard foi desenvolvido com foco em clareza, organização e facilidade de uso.
