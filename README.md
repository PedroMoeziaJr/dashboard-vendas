# Dashboard de Vendas Xbox

Este projeto apresenta uma dashboard interativa com dados de vendas e assinaturas do ecossistema Xbox. A visualização inclui métricas como total de assinantes, receita total, ARPU, distribuição de planos, tipos de assinatura, auto-renovação e uso de Season Pass (EA Play e Minecraft).

Os dados utilizados são fictícios e servem para fins de análise e demonstração.
